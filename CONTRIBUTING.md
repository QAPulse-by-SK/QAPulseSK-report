# Contributing to QAPulseSK-report

Thank you for your interest in contributing! We welcome all contributions.

## Getting Started

```bash
git clone https://github.com/QAPulse-by-SK/QAPulseSK-report.git
cd QAPulseSK-report
npm install
npm run build
```

## Development

```bash
npm run build:watch   # TypeScript watch mode
npm test              # Run tests
npm run lint          # ESLint
```

## Pull Request Guidelines

- One feature or fix per PR
- Follow the existing code style (TypeScript strict mode)
- Add tests for new functionality
- Update README.md if adding new config options
- PRs reviewed within 48 hours

## Reporting Issues

Use [GitHub Issues](https://github.com/QAPulse-by-SK/QAPulseSK-report/issues).
Include: framework version, Node.js version, config used, and error output.
